# E-commerce System (Shopee Simulation)

## Project Overview

This project was developed as part of the **Modern Database Management (CSC12002)** course at the **University of Science, Vietnam National University - Ho Chi Minh City**.  
It simulates an **e-commerce system (Shopee)** and focuses on analyzing requirements, designing NoSQL databases, and implementing system modules with a **microservices architecture**.

## Deployment Instructions

The system has not been deployed to a public server.  
To run the project locally:

1. Run the docker-compose.yml file in /src.  
2. Start the microservices modules.  
4. Access the system interface via localhost.  

---

## Key Features

- Reverse engineering functional requirements of Shoppe.  
- Using different NoSQL databases to handel system requirements.  
- Implement selected functionalities with NoSQL databases (Web page): Cart, Product, Rating, Purchases.  

For more details, please refer to the project report.
